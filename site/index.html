How it works

Up and running in three steps

Your IT person sets up the office server once. After that, this is all anyone needs to do.

  1. 1

    Install

    Download the setup and run it. It installs just for you, so you do not need an administrator.

  2. 2

    Sign in

    Open File › Shared. The office server shows up on its own. Type the user name and password IT gave you.

  3. 3

    Share and edit together

    Open any file from your folder or the network drive and click Share › Share with my team. Everyone's edits appear live, and your file keeps them.

What it does for you

Built for a design office that shares its numbers

Live editing

Share any file, from where it is saved

Open a workbook from your D: drive, a project folder or the network drive and share it. It stays right where it is: your team edits it with you live, and the file is saved with everyone's changes as they happen. Other people's selected cells are outlined in their colour with their name.

  • No waiting for someone to close the file, no emailed copies
  • Someone opens the same file? They join you, so it never splits into two versions
  • Stop sharing hands the file back with every edit in it
  • Network dropped? Keep typing. Your edits wait and go through when it comes back.
  • Undo takes back your edits, never a colleague's

Named accounts

Everyone signs in, so every change has a name

Shared workbooks need a named account. There are no guests and no anonymous edits, so the workbook can always answer: who changed this cell, when, and what was it before?

  • The office server is found on the network by itself
  • The status bar shows who last changed the cell you are on
  • IT decides who can edit and who can only view

Edit History

See every change: old value, new value, who and when

Click the “last changed by” note in the status bar, or open Review › Edit History. You get the story of one cell or of the whole workbook, and you can filter it by person.

  • Values that only recalculated are never blamed on anyone
  • Useful when a client asks “who changed this length, and when?”

Versions

Go back to any earlier version

The server keeps a version every hour while people work, every time someone presses Save, and whenever you ask (“Issued for review Rev B”). Open any of them as a separate copy, or restore one for everyone.

  • Before any restore, the current state is kept too, so nothing is lost
  • Every edit reaches the server's disk before anyone else sees it

Excel files in and out

Clients send .xlsx. You send .xlsx back.

Open any Excel workbook, share it with the team, and use File › Save As to send an .xlsx copy out. Tables, charts, conditional formatting and more than 500 functions all work, and Indian number formats like 12,34,567 and dd-mm dates follow your Windows settings, just as Excel does on your PC.

  • Files we write open in Excel with no repair prompts in our tests
  • Excel recalculating our files gives the same numbers

Updates itself

Always the latest version, with one click

When a new version is out, every running copy shows Update to … in the status bar. Click Update now: it downloads from the office server, checks the file and installs itself, then reopens. Shared work is already saved on the server, so nothing is lost.

  • No administrator rights needed
  • PCs never need internet access; the office server brings the update

Formulas, formatting, charts and dark mode

Questions

Good to know

Do I need administrator rights to install it?

No. The setup installs Dexterity Sheets just for your Windows account, so you can install it and update it yourself.

Can I open my existing Excel files?

Yes, from wherever they are saved. Open the file as usual and click Share › Share with my team to work on it with others: it stays in its folder and keeps everyone's edits. To send a file to a client, use File › Save As and pick .xlsx. Excel opens those files without complaint.

Do I still need to press Save?

Not in a shared workbook. Every change reaches the office server as you make it, and a file you shared is saved with everyone's edits a moment after each change. Ctrl+S saves the file at once and keeps a named version you can go back to later.

What if two people change the same cell?

The server puts the two changes in order and the later one wins. Everyone ends up seeing exactly the same thing, and Edit History keeps both, so nothing disappears without a trace. Changes to different cells never get in each other's way.

What happens if the network drops?

Keep working. Your edits are kept on your PC and the status bar shows how many are waiting. They are sent as soon as the office server can be reached again.

Can a colleague undo my work by mistake?

No. Undo only takes back your own edits. And if something does go wrong, any earlier version can be opened as a copy or restored.

How do I get an account?

Ask your IT person or office administrator. Accounts are created on the office server; there is no sign-up form and no guest access. IT can make you an editor, or a viewer who can only read.

Is anything sent to the internet or the cloud?

No. Your files stay in your folders, and the office server on your own network passes edits between PCs and keeps the history. There is no cloud service, no subscription and no tracking. Your PC does not even need internet access to get updates.

Does it work on a Mac or at home?

Dexterity Sheets is made for Windows 10 and 11 PCs in the office. Shared workbooks need the office network; on its own the app opens and saves .xlsx files anywhere.

Under the hood

A native Windows app written in Rust, built on GridCraft {{GRIDCRAFT}}, an open-source, Excel-compatible spreadsheet engine. Dexterity adds live co-authoring over the office LAN: a small server program, named accounts, an audit trail of every cell change, versions and update distribution. Fixes from GridCraft flow in automatically, are tested, and are released through the built-in updater.
